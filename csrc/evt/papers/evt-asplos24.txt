A.3 Description

A.3.1 How to access. The source code is publicly available
at https://github.com/apuaaChen/EVT_AE/tree/main and
https://zenodo.org/doi/10.5281/zenodo.10790585.

A.3.2 Hardware dependencies. To reproduce the results,
a single A100 GPU with at least 40GB HBM is required. The
CPU should not influence the results, but may have impact
on the compilation time.

A.3.3 Software dependencies. The Dockerfile provided
is built from docker image nvcr.io/nvidia/pytorch:23.07-py3.
Other dependencies are specified in the Dockerfile. Notably,
small changes are automatically applied to the source code
of PyTorch to workaround certain issues when tracing GCNs
with torch.compile.

A.3.4 Data sets. . The GCN is evaluated on the ogbn-mag
dataset. Others use synthesized inputs.

The detailed installation steps are in EVT_AE/README.md.

A.5 Experiment workflow

Follow the steps in EVT_AE/README.md, launch the two
scripts: `bash figure12.sh` and `bash figure13_17.sh`.
